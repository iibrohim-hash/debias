# Notebooks

One notebook per person for experiments, named `<letter>_<topic>.ipynb` (e.g. `A_detector.ipynb`, `D_rag.ipynb`).
Start every new notebook from `00_template.ipynb`, which sets up Colab, Kaggle and local Jupyter the same way.
When a function works, move it into `src/` and import it from there.
Clear outputs before committing large notebooks (Edit > Clear all outputs) to keep diffs small.
